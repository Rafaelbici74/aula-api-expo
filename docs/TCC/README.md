# Documentação do TCC

Esta pasta é reservada exclusivamente às instruções e materiais de documentação do TCC.

## Instruções disponíveis

- `documentar-projeto.md`: analisa o projeto e retorna texto técnico formatado para inserção no TCC.
- `capturar-telas.md`: orienta a captura de telas solicitadas para uso na documentação.

As regras acadêmicas específicas, instituição, normas de formatação, metodologia e estrutura dos capítulos ainda não foram fornecidas. Não invente essas regras. Quando forem definidas, crie documentos separados e mantenha-os independentes das instruções de desenvolvimento em `docs/project`.
