# Documentação e manutenção

- Mantenha documentação coerente com o código e o banco reais.
- Atualize documentos temáticos quando uma decisão arquitetural ou regra reutilizável mudar.
- Não duplique instruções entre `AGENTS.md` e `docs/project`; o primeiro contém regras gerais e os segundos detalhes temáticos.
- Não crie documentação acadêmica em `docs/project`.
- Não invente exemplos que possam ser confundidos com dados reais.
- Ao concluir uma alteração, informe arquivos, banco afetado, validações e limitações.
