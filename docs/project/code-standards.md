# Padrões de código

- Use JavaScript conforme o projeto atual; não introduza TypeScript sem aprovação.
- Preserve nomes, imports, exports, organização de funções e convenções existentes.
- Prefira funções pequenas, validações explícitas e código legível.
- Evite casts frágeis, duplicação, abstrações especulativas e refatorações fora do escopo.
- Não silencie erros com catches amplos ou retornos que simulem sucesso.
- Comente apenas lógica não óbvia e mantenha comentários atualizados.
- Remova imports e componentes não utilizados quando forem parte da alteração aprovada.
